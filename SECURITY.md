# Security Policy

## Supported Versions

The latest released version receives active security support and bug fixes.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | Yes                |
| < 1.0   | No                 |

## Reporting a Vulnerability

If you discover a security vulnerability within PriceScout-ZA, please do not disclose it publicly in an open GitHub issue.

Instead, please report security vulnerabilities using GitHub Private Vulnerability Reporting:
1. Navigate to the repository's Security tab: `https://github.com/Xander-Coetzee/price-scout-za/security`
2. Click "Report a vulnerability"
3. Provide details including reproduction steps, impact, and suggested remediations.

Alternatively, contact the repository maintainers directly through GitHub profiles.

We will review reports within 48 hours and work with you on a coordinated disclosure and patch release.
